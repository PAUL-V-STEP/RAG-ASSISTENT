# Этап 0. Состояние проекта assistant_api (до/в ходе реализации ТЗ-RAG-AL)

## 1. Точка входа

- Консоль: `python -m assistant_api.app` (`assistant_api/app.py`).
- Вопрос → `RAGPipeline.query()` → ретривер Chroma (`VectorStore.search`) → OpenAI Chat Completions → ответ.
- HTTP API нет и не добавляется.

## 2. База знаний и Chroma

- Раньше: `assistant_api/data/docs.txt` (ML/NLP), загрузка только при `collection.count() == 0`, каталог `assistant_api/chroma_db`, коллекция `api_rag_collection`.
- Теперь: `DATA_FILE` = `ТО автолифта АЛ 3У-М6 — версия для RAG V3.txt` в корне проекта; путь от корня.
- Коллекция: `kb__<kb_version>`, `kb_version` = sha256 файла, 12 символов.
- При смене файла — новая коллекция; `--rebuild-kb` удаляет и создаёт заново.
- Загрузчик останавливается, если в файле есть `[вопрос-ответ]` / «ВОПРОСЫ И ОТВЕТЫ».
- Чанкинг не менялся (абзацы / предложения, 500/100).

## 3. Семантический кэш (подтверждено по коду)

- Хранилище: SQLite, не отдельная библиотека векторного поиска.
- Было: SHA-256 нормализованного сырого вопроса, затем cosine similarity всех embeddings.
- Метрика: **косинусное сходство** (больше — ближе).
- Пороги в коде до переименования:
  - `CACHE_EXACT_SIMILARITY_THRESHOLD` = **0.97** → `SEMANTIC_CACHE_STRICT_MIN_SIMILARITY` (почти идентичный вектор / «exact» по cosine).
  - `CACHE_SEMANTIC_SIMILARITY_THRESHOLD` = **0.88** → `SEMANTIC_CACHE_MIN_SIMILARITY` (тот же смысл, другая формулировка).
- TTL: **не было** → `SEMANTIC_CACHE_TTL_S=0`.
- top-k: сканировались все строки; в ТЗ диапазон 1–20 → по умолчанию **20**.
- Фильтров и привязки к базе знаний не было; добавлены `kb_version` и слоты.
- `check`/`store`: `RAGCache.get` / `set` из `RAGPipeline.query`.

Кэш адаптируется без полной замены SQLite: новые колонки + имя файла `cache__<kb_version>.db`. Старый `api_rag_cache.db` на docs.txt не читается новым индексом.

## 4. Клиент LLM

- OpenAI, модель по умолчанию `gpt-4o-mini`.
- Chat Completions, `messages` system+user.
- JSON mode: `response_format={"type":"json_object"}` для contextualization; temperature 0; таймаут `NORMALIZER_TIMEOUT_S`.

## 5. Формат `[глоссарий]`

Строка: `[глоссарий] КАНОН — определение. Синонимы и варианты запроса: … Где встречается: …`

Примеры:

- `[глоссарий] ТО-1 — техническое обслуживание № 1; … Синонимы и варианты запроса: ТО1, ТО 1, первое техническое обслуживание, техобслуживание № 1.`
- `[глоссарий] гидросистема — гидравлическая система … Синонимы: гидравлическая система, гидравлика, гидропривод.`
- `[глоссарий] оборудование — …` → `type: product` (не слот Entities).

В файле комплекта **38** строк `[глоссарий]`, блока `[вопрос-ответ]` нет.
